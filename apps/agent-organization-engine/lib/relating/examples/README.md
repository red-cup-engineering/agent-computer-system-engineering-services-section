# Examples

Examples are exposure paths, not proof substitutes. Run them after building:

```sh
pnpm run build
pnpm run examples
```

- `material/camera-exposure.mjs` follows one admitted specimen through aperture,
  lens, sensor, development bath, phase plate, projection, and ledger handles.
- `package/package-phase.mjs` shows the package membrane: realized carriers,
  registered actions, generated discovery, and owned wire codecs.
- `package/action-projection.mjs` shows OpenAPI/MCP projections generated from
  the same action apex without opening a service port.
- `services/cli-exposure.mjs` shows the built CLI binding stdin/argv to package
  dispatch.
