# @red-cup-engineering/relational-domain-provider

This is the narrow relational domain provider used by `@red-cup-engineering/agentic-communication-engine`.
It delegates articulation and predication to `@lenticule-science/articulating`, delegates
the RMN grammar, JSON bridge, typing, and evaluation to the split RMN packages, and owns
only the carrier/action boundary plus the finite Chu and cohomology term catalogs still
required by communicating.

It deliberately contains no semantic-content identity, omnibus runtime, legacy
`ascribe`, RDF, HTTP, filesystem, or custody implementation.
