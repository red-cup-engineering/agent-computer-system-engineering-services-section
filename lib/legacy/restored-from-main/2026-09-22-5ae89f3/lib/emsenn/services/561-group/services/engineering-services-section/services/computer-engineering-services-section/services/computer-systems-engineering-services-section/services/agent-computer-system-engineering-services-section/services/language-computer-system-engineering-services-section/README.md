# Language Computer System Engineering Services Section

This section contains executable language-system carriers. It composes
language fibers into parsers, forests, repairs, and interfaces; linguistic
evidence, lexicons, and theory remain independent scientific inputs.

- `apps/panini/` reads a selected language fiber into a source-preserving
  forest and exposes that operation as a library and CLI.
- `services/*-language-algebra/` provide executable language fibers for
  English, Lakota, Latin, Mandarin, and Toki Pona.
- `apps/lakota-language-corpus/` compiles and serves the Lakota language
  bundle. Its curated linguistic materials remain visible inputs to the
  runtime rather than claims made by this engineering section.
